### 3. Замена main.rs

После завершения п.1 и п.2, замените содержимое **src/main.rs** на:

```bash
# В командной строке:
rm src/main.rs
mv src/main_new.rs src/main.rs
```

Или вручную замените содержимое src/main.rs на:

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

mod config;
mod i18n;
mod image;
mod utils;
mod video;
mod upload;
mod app;

use app::{ScreenlistApp, setup_custom_style};

fn main() -> eframe::Result<()> {
    video::ffmpeg::init();

    let options = eframe::NativeOptions {
        viewport: eframe::egui::ViewportBuilder::default()
            .with_title("⚡ Генератор скринлиста PRO")
            .with_inner_size([1360.0, 860.0])
            .with_min_inner_size([960.0, 620.0])
            .with_drag_and_drop(true),
        ..Default::default()
    };

    eframe::run_native(
        "screenlist-rs",
        options,
        Box::new(|cc| {
            setup_custom_style(&cc.egui_ctx);
            Box::new(ScreenlistApp::new())
        }),
    )
}
```

## 🔧 Исправление ошибок компиляции

После переноса кода выполните:

```bash
cargo check
```

Типичные ошибки и их исправление:

1. **Отсутствующие импорты** - добавьте `use crate::module::Type;`
2. **Приватные поля** - добавьте `pub` к полям в struct
3. **Отсутствующие функции** - убедитесь, что все вспомогательные функции перенесены
4. **probe_video не найден** - используйте `crate::video::ffmpeg::probe_video`
5. **libav не найден** - замените на `crate::video::ffmpeg`
