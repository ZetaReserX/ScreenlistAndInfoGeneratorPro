## 🚀 Как завершить

### Шаг 1: Завершить app.rs

Откройте **src/main.rs** и **src/app.rs** рядом:

1. Найдите в main.rs строку 2672 (`fn add_video_paths`)
2. Скопируйте ВСЕ методы из `impl ScreenlistApp` (строки 2672-5126)
3. Вставьте в app.rs вместо комментария "// ВРЕМЕННАЯ ЗАГЛУШКА"

4. Найдите в main.rs строку 5127 (`impl eframe::App for ScreenlistApp`)
5. Скопируйте полный метод `fn update` (строки 5127-5885)
6. Замените заглушку в impl eframe::App

### Шаг 2: Заменить main.rs

```bash
# Удалите старый main.rs
rm src/main.rs

# Переименуйте новый main
mv src/main_new.rs src/main.rs
```

Или просто замените содержимое src/main.rs на содержимое src/main_new.rs

### Шаг 3: Компиляция и исправление

```bash
cargo check
```

**Возможные ошибки:**

1. **Отсутствующие импорты в app.rs** - добавьте:
```rust
use crate::video::{compose_contact_sheet, extract_chunk_frames_rgb, ...};
```

2. **probe_video не найден** - замените на:
```rust
use crate::video::probe_video;
```

3. **libav не найден** - замените на:
```rust
use crate::video::ffmpeg;
```

4. **Функции не pub** - добавьте `pub` к функциям в processor.rs если нужно

### Шаг 4: Финальная проверка

```bash
cargo build --release
cargo run
```
